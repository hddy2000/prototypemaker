# 盲盒赌场 - 策划案

> 一群戴罗马面具的赌狗闯进废弃剧院开盲盒，捡东西卖给入口的鉴宝商人，攒够钱撤离。

---

## 一、核心循环

```
入口（鉴宝商人）
  ↓
进剧院 → 找盲盒 → 按住空格敲盲盒（站着不动，怪物可以来咬）
  ↓
盲盒裂开 → 掉出物品（普通/未鉴定/武器）→ 捡进背包（4格）
  ↓
回入口 → 卖给商人 → 揭晓未鉴定价格 → 攒钱
  ↓
钱够了吗？
  ├─ 不够 → 再进去冒险（深处盲盒更好但更远更危险）
  └─ 够了 → 撤离 → 结算
```

---

## 二、撤离条件

- **攒够 ¥1000 才能撤离**
- 撤离点 = 入口（鉴宝商人位置）
- 没有倒计时催命符，**钱就是倒计时**——你待越久怪物越多越强，逼你权衡"再开一个还是见好就收"

## 四、盲盒系统

### 4.1 盲盒类型

| 盲盒 | HP（敲击次数） | 开盒时间 | 出物品品质 | 出武器概率 | 分布位置 |
|------|----------------|----------|-----------|-----------|----------|
| 小盒 | 3击 | ~3秒 | 低 | 10% | 浅层多 |
| 中盒 | 6击 | ~6秒 | 中 | 20% | 中层多 |
| 大盒 | 10击 | ~10秒 | 高 | 35% | 深层多 |

### 4.2 开盒机制

```
走到盲盒旁 → 按住空格 → 角色自动敲击 → HP逐渐降低
  ↓
松手 = 停止敲击（HP保留，可回来继续敲）
  ↓
HP归零 → 盒子裂开 → 掉出1个物品
  ↓
敲击时角色站着不动 → 怪物可以来咬你
  ↓
没有无敌帧 → 要随时准备松手跑路
```

### 4.3 盲盒数量

- 浅层：8-10个小盒
- 中层：5-6个中盒
- 深层：3-4个大盒
- 总计：约18-20个盲盒

## 七、怪物设计

### 7.1 设计原则

参考 `docs/monster-ai-design.md`，做两只相对简单的怪物：
- 一只**标准怪**（可打断，杀不死，提供持续压力）
- 一只**谜题怪**（有独特AI规则，理解了就能应对）

### 7.2 怪物一：群演幽灵（标准怪）

**参考：** Lethal Company 的 Hoarding Bug + Thumper

| 参数 | 值 |
|------|-----|
| 类型 | 自由漫游型 |
| 感知方式 | 视线 |
| 感知范围 | 180px |
| 巡逻速度 | 40 |
| 追击速度 | 150 |
| 放弃条件 | 断视线5秒 |
| 放弃后行为 | 继续漫游 |
| 能杀吗 | ❌ 杀不死，只能扔东西打断 |
| 扔东西效果 | 被砸中后眩晕2秒，然后继续追 |
| 伤害 | 15/次 |
| 攻击间隔 | 1秒 |

**行为状态机：**

```
漫游（随机方向走，碰墙转向）
  ↓ 看到玩家（视线范围内）
追击（直线冲向玩家）
  ↓ 玩家拐弯/躲到障碍后断视线
丢失目标 → 5秒后回到漫游
  ↓
追击中被扔东西砸中 → 眩晕2秒 → 继续追
```

**应对方式：** 绕障碍物拐弯断视线，或扔东西眩晕2秒争取跑路时间。

### 7.3 怪物二：掌声判定者（谜题怪）

**参考：** Lethal Company 的 Eyeless Dog + Nutcracker

| 参数 | 值 |
|------|-----|
| 类型 | 巡逻路线型 |
| 感知方式 | 听觉（检测移动声音） |
| 感知范围 | 250px |
| 巡逻速度 | 50（沿固定路线走） |
| 追击速度 | 170 |
| 放弃条件 | 听不到声音5秒 |
| 放弃后行为 | 回到巡逻路线 |
| 能杀吗 | ❌ 杀不死 |
| 扔东西效果 | 被砸中后眩晕3秒 |
| 伤害 | 25/次 |
| 攻击间隔 | 1.5秒 |

**行为状态机：**

```
巡逻（沿固定路线走，定期停步"听"2秒）
  ↓ 听到移动声音（跑/走/敲盲盒）
锁定声源方向 → 加速冲向声源
  ↓
追击中：
  玩家跑 → 持续追（跑动声大）
  玩家蹲走 → 声音减小 → 追击速度降低
  玩家完全不动 → 听不到声音 → 5秒后放弃
  ↓ 放弃后
回到巡逻路线继续走
```

**独特规则：** 蹲走不发出声音 = 隐身。跑动 = 大声 = 必定被发现。敲盲盒 = 巨响 = 必定被吸引。

**应对方式：**
- 听到它在附近 → 蹲走绕过
- 正在敲盲盒时它来了 → 松手停敲 → 蹲走离开
- 被追了 → 扔东西砸它眩晕3秒 → 跑到障碍后断视线 → 蹲走

### 7.4 怪物刷新

| 时间阶段 | 刷新数量 | 刷新类型 |
|----------|----------|----------|
| 开局 | 3只群演幽灵 | 散布在中层和深层 |
| 玩家赚到¥300后 | +2只群演幽灵 | 从深层刷新 |
| 玩家赚到¥600后 | +1只掌声判定者 | 从深层巡逻 |
| 玩家赚到¥800后 | +1只群演幽灵 | 从浅层堵回程 |

**没有硬倒计时，钱就是倒计时**——赚越多怪物越多越强，逼你"见好就收"。

## 八、鉴宝商人

### 8.1 位置

固定在入口（地图左上角），永远在那。

### 8.2 功能

| 功能 | 说明 |
|------|------|
| 鉴定收购 | 卖东西给商人，未鉴定物品此时揭晓价格 |
| 撤离判定 | 累计赚到¥1000 → 可以撤离 |
| 成色修复 | 花原价50%修复成10成新（可选功能） |

### 8.3 交互方式

走到商人旁 → 显示背包 → 逐个卖（或批量卖）→ 钱累加 → 够¥1000显示"可以撤离" → 按E撤离

## 九、操作设计

| 按键 | 动作 | 说明 |
|------|------|------|
| WASD | 移动 | — |
| Shift | 疾跑 | 消耗体力，跑动声大（吸引掌声判定者） |
| Ctrl/C | 蹲走 | 无声音，慢但隐身于听觉怪 |
| 空格 | 敲盲盒 | 按住=持续敲，松手=停（HP保留） |
| 左键 | 扔物品 | 朝鼠标方向扔手持物品砸怪 |
| Q | 丢地上 | 把手持物品丢脚边给队友捡 |
| 滚轮 | 切换手持 | 切换背包4格中哪个在手持槽 |
| E | 交互 | 捡物品/与商人交易/撤离 |
