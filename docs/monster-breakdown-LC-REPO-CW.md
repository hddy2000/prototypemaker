## 一、Lethal Company（致命公司）— 32 只实体

> HP 以"铲子击数"为单位（1 铲子 = 1 HP）。分为室内 / 室外夜间 / 白天三类。

### 室内实体（19 只）

---

### 1. Bracken / Flowerman（花人 / 蕨人）

| 维度 | 拆解 |
|------|------|
| **机动性** | 中快。**不随机漫游**——始终最优路径绕到玩家**背后**，从不在正面出现。可跨楼层躲藏。被发现时**倒退高速撤退**。 |
| **攻击方式** | **接触即秒杀**——扭脖子，然后把尸体拖到它的"专属房间"。无前摇。 |
| **仇恨机制** | **全知**——始终知道设施内所有玩家的位置和朝向。追最近的玩家。受伤后进入暴怒态，追最近的玩家（不分谁打的）。**不呼叫同伴**。 |
| **感官机制** | 室内全知（知道所有人位置/朝向）。**凝视机制**：被瞥见→撤退；被长时间盯着→**愤怒值**累积（0.2 秒怒/0.2 秒被盯），满后暴怒。黑暗中可见发光白眼。 |
| **可击杀** | ✅ 5 HP。但受伤瞬间进入暴怒态。双管猎枪最佳（1 HP/发）。 |
| **放弃机制** | 撤退态持续 24 秒（仅在不被看时倒计时）。每日最多刷 1 只。 |
| **刷新** | 室内。偏好月亮：Vow（21%）。 |
| **独特** | 三阶段：狩猎→撤退→暴怒。愤怒值不自然衰减。拖尸是标志性行为。 |

### 2. Coil-Head（弹簧头 / 线圈头）

| 维度 | 拆解 |
|------|------|
| **机动性** | 中（约等于玩家冲刺速度）。在两个随机区域间漫游；建立视线后追设施内所有玩家。**只在不被看时移动/攻击**。 |
| **攻击方式** | 90 伤害/次，0.2 秒攻速（450 DPS）——实际秒杀。斩首，脖子换成弹簧。 |
| **仇恨机制** | 一旦有玩家在视线内，追**设施内所有玩家**（不分视线）。目标死了/离开则切换。无玩家时回巡逻。 |
| **感官机制** | **视觉（凝视机制）**。视野从脚部发出，玩家必须看其**骨盆/腰部**才能冻结它。巡逻态看头有效，追击态看腰有效。 |
| **可击杀** | ❌ 无敌。只能眩晕（眩晕倍率 3.25x，全游戏最长）。 |
| **放弃机制** | 追 35 秒后进入休息/充能态约 15 秒（头缩下休眠）。 |
| **刷新** | 室内。偏好：Offense（11%）。最多 5 只。 |
| **独特** | Weeping Angel / SCP-173 机制。关门极慢（0.06），关门可逃生。 |

### 3. Nutcracker（胡桃夹子）

| 维度 | 拆解 |
|------|------|
| **机动性** | 中。巡逻走廊，定期停步 360° 扫描。巡逻时无敌，**只有眼睛伸出时可受伤**。 |
| **攻击方式** | 两种：**霰弹枪射击**（5–100 伤害按距离，约 1 秒前摇，1.5 秒装弹）+ **踢击**（接触秒杀，但只在非射击/装弹时）。 |
| **仇恨机制** | 70° 视野扫描**移动**，每 30° 停一次。检测到移动→锁定该玩家。会蹲守停止移动的玩家（等他动再射）。v47 起可微移瞄准。 |
| **感官机制** | **运动视觉**——头抬起时伸出的单眼检测。摄像机移动、蹲下、表情都算移动。未被检测的玩家可自由攻击它。 |
| **可击杀** | ✅ 5 HP，但只有眼睛伸出时。最后一击触发暴怒（射速加快）。掉落双管猎枪 + 2 发子弹。 |
| **放弃机制** | 失去目标后回巡逻。最多 10 只。 |
| **刷新** | 室内。偏好：Rend（23%）。有"虫害"事件（0.725%/天）。 |
| **独特** | 唯一有致命远程攻击的怪 + 两种攻击。掉落可用武器。霰弹可杀其他实体。 |

### 4. Jester（小丑 / 音乐盒）

| 维度 | 拆解 |
|------|------|
| **机动性** | 慢漫游→跟随玩家→**上发条**（静止 42 秒）→**追击**（速度递增，最终超过冲刺）。 |
| **攻击方式** | 追击态**接触秒杀**。用嘴咬住尸体片刻后丢下追下一个。 |
| **仇恨机制** | **全知**——不靠声/光/移动，一旦锁定跟随就无法甩掉，**只能离开设施**。 |
| **感官机制** | 无感官检测——锁定后全知。跟随阶段持续 13–18 秒（多人）/ 25–42 秒（单人）。 |
| **可击杀** | ❌ 无敌。只能拖延（电击枪最多拖延上发条 20 秒）。 |
| **放弃机制** | 设施内无活玩家时回漫游。速度在击杀/眩晕/闪光后重置。 |
| **刷新** | 室内。偏好：Rend（14%）。最多 1 只。Power 3。 |
| **独特** | 三阶段：漫游→上发条（播放"Pop Goes the Weasel"，越来越快/疯狂）→追击。尖叫会引来无眼犬。最佳对策：离开设施。 |

### 5. Ghost Girl / Dress Girl（幽灵女孩 / 裙子女孩）

| 维度 | 拆解 |
|------|------|
| **机动性** | 传送/跳跃式接近目标。可出现在室内或室外。**对目标以外的玩家隐形**。 |
| **攻击方式** | 追击态**接触秒杀**（斩首）。 |
| **仇恨机制** | **一次只附身一人**——积分系统：基础 80 + 最高理智值(+50) + 最偏执/转头最多(+30) + 持有>150c 废品(+30) + 从未重伤(+10)。目标死后选新目标。 |
| **感官机制** | **视线"捉迷藏"机制**。五状态：缺席→凝视→消失→隐匿→追击。看她累积"被盯次数"；3–4 次被看或 3 次未看→85% 概率追击。5 单位内算"在看"。追击时不被看可传送。 |
| **可击杀** | ❌ 无敌且免疫所有眩晕。 |
| **放弃机制** | 追击持续 20 秒或目标移动>50 单位，回缺席。可从不看她、保持>50 单位、或蹲在飞船柜子上（安全点）规避。 |
| **刷新** | 室内（但跟随目标到任何地方，含室外/飞船）。偏好：Rend（4.68%）。最多 1 只。无图鉴条目。 |
| **独特** | 唯一只对一个玩家可见的实体。征兆：灯闪、咯咯笑/呼吸、闷声音频、落地钟声。淋浴可阻断视线阻止生成。 |

### 6. Thumper / Crawler（重击者 / 爬行者）

| 维度 | 拆解 |
|------|------|
| **机动性** | **直线极快**（加速到玩家跑不过），但**拐弯极差**。聋。 |
| **攻击方式** | 40 伤害/咬，4 咬致死。发现目标时咆哮。 |
| **仇恨机制** | 纯视觉检测。断视线后调查最后看到的位置。 |
| **感官机制** | **纯视觉——完全聋**。听不到任何声音。 |
| **可击杀** | ✅ 4 HP。切换目标/被击中/攻击/撞墙/被眩晕时失去所有速度。 |
| **放弃机制** | 调查最后已知位置；失去目标后回漫游。最多 4 只。 |
| **刷新** | 室内。偏好：Offense（22%）。Power 3。 |
| **独特** | 软骨骨架（鲨鱼/鳐鱼状）。头部受击免疫菜刀。最佳对策：拐弯断视线、倒退+敲。 |

### 7. Hygrodere / Blob / Slime（史莱姆 / 黏液怪）

| 维度 | 拆解 |
|------|------|
| **机动性** | **极慢**。知道设施内所有玩家位置，追最近的。可开门（少见）。玩家拿收音机时大幅加速。 |
| **攻击方式** | 35 接触伤害（DoT，在里面持续掉血）。击杀后完全吸收身体（只剩空衣服）。 |
| **仇恨机制** | 始终知道所有玩家位置。无玩家时移向最后已知位置。 |
| **感官机制** | 全知定位（非视觉/听觉）。 |
| **可击杀** | ❌ 免疫所有武器（尖刺陷阱除外，有 bug）。 |
| **放弃机制** | 不算放弃，但极慢。v80 起无玩家时用标准寻路（不再蹲出口）。 |
| **刷新** | 室内。偏好：Offense（14%）。最多 2 只。 |
| **独特** | 可变大小（激动时变大）。收音机驯化机制（在静止收音机上跳舞时无害）。游戏内最不危险的敌怪。 |

### 8. Hoarding Bug / Loot Bug（囤积虫 / 拾荒虫）

| 维度 | 拆解 |
|------|------|
| **机动性** | 中。漫游搜废品，回巢。激动时可飞。 |
| **攻击方式** | 30 伤害。三档仇恨：轻（接近，追几秒）、中（被击，断视线 15 秒后放弃）、最高（巢被偷，追到死/死/归还物品）。 |
| **仇恨机制** | 接近巢穴/被击/巢被偷触发。巢被偷即使虫没看到也触发。 |
| **感官机制** | **听觉**（蹲走/走路/冲刺/语音/手电开关声）近巢触发守卫。视觉发现/追踪玩家。 |
| **可击杀** | ✅ 3 HP。 |
| **放弃机制** | 轻：几秒。中：断视线 15 秒。最高：只有击杀/死亡/归还**同一件**被偷废品。最多 10 只。 |
| **刷新** | 室内。偏好：Embrion（27%）。有"虫害"事件（2.9%/天）。 |
| **独特** | 收集/囤积废品到巢。丢物品可安抚。会跟着拿废品的玩家。 |

### 9. Bunker Spider（地堡蜘蛛）

| 维度 | 拆解 |
|------|------|
| **机动性** | 慢。漫游织网；网被触碰/破坏或蜘蛛被碰时追。快死时加速。 |
| **攻击方式** | 90 伤害（两下致死）。拖尸体到巢用丝包裹（无传送器则不可取回）。 |
| **仇恨机制** | 领地型——网接触/近战破网/碰蜘蛛触发。织很多网后可能进入伪狩猎模式。 |
| **感官机制** | 网触发（接近/接触）。狩猎后视觉。 |
| **可击杀** | ✅ 5 HP。不能跨断层房间。 |
| **放弃机制** | 持续追但慢；走路速度就能甩掉。最多 1 只。 |
| **刷新** | 室内。偏好：Experimentation（25%）。 |
| **独特** | 蜘蛛恐惧症模式替换为漂浮"Spider"文字。网减速玩家。开门极慢（0.15）。 |

| **独特** | Headcrab/Facehugger 机制。摇头甩不掉。附着时屏幕右上角有小洞。队友可用铲子/电击枪杀。 |

### 12. Butler（管家）

| 维度 | 拆解 |
|------|------|
| **机动性** | 漫游扫地。6 秒没看到玩家时跑。谋杀阶段冲刺。 |
| **攻击方式** | 10 伤害（菜刀快速刺）。死亡时爆炸 30 伤害+击退。 |
| **仇恨机制** | 多人在场时被动。**针对落单玩家**（独处 6 秒→徘徊态；12 秒不见他人→谋杀态）。切最近目标。被以下触发暴怒：非菜刀近战击中、被看到和尸体在一起、长时间接触（14%/0.25 秒）。多管家连锁暴怒。 |
| **感官机制** | 视觉（可穿门看）。追最近玩家。 |
| **可击杀** | ✅ 8 HP（多人）/ 2 HP（单人）。菜刀 1 击致死。死亡掉落菜刀+生成面具胡蜂。 |
| **放弃机制** | 杀人后逃跑 15 秒，回漫游。最多 7 只。 |
| **刷新** | 室内。偏好：Dine（16%）。v80 起不在 Adamance。 |
| **独特** | 四阶段：漫游→徘徊→谋杀→暴怒。死亡生成面具胡蜂+爆炸。免疫震撼弹。 |

### 13. Maneater（食人兽 / 洞穴居者）

| 维度 | 拆解 |
|------|------|
| **机动性** | 幼体：跟随/漫游。成体：守巢，**潜行绕到玩家背后**（视线外偷袭），**突进极快**（无视地形）。**室外突进速度 2 倍**。 |
| **攻击方式** | 成体**接触秒杀**（撕咬）。攻击循环：0.5–1 秒冲刺 + 1.5–2 秒停顿。 |
| **仇恨机制** | 幼体对第一个看到的玩家印随（100%好感，后续 50%）。成体：攻击最后看到的玩家；领地内感知玩家位置（30–100 单位范围）。看着成体但不靠近→撤退+绕圈伏击。假幼体哭声诱骗玩家。 |
| **感官机制** | 幼体：听觉（声音触发哭泣）。成体：视觉+领地接近感知。领地内无视视线感知玩家。 |
| **可击杀** | 幼体：**无敌**（秒杀伤害反而触发变形）。成体：**5 HP**，但所有非秒杀伤害每击上限 1 HP。免疫震撼弹。 |
| **放弃机制** | 所有玩家>14 单位且不可见，或所有玩家离开领地时退出攻击态。最多 1 只。 |
| **刷新** | 室内（可被玩家带到室外）。矿道内刷新率 1.7 倍。偏好：Vow（14%/24%）。 |
| **独特** | 幼体→成体变形（室内哭泣 17 秒，不可逆）。必须"摇"来安抚。幼体可拾取（双手，21 磅）。吃东西变胖（外观）。**别把幼体带到室外**（哭、无法安抚、变形更快、突进 2 倍速）。 |

### 14. Masked / Mimic（面具人 / 模仿者）

| 维度 | 拆解 |
|------|------|
| **机动性** | 走/冲刺。可快速爬梯。可离开设施（仅主入口，且设施内无活玩家时；室外无人时重新进入）。 |
| **攻击方式** | **秒杀**——抓住玩家，将其转化为面具人（非普通尸体）。转化需几秒（可击杀/眩晕/传送窗口）。 |
| **仇恨机制** | 追第一个看到的玩家；忽略其他人，除非原目标断视线 10 秒或死亡。可在飞船藏身（22 米内，漫游态）。 |
| **感官机制** | 视觉（视线）。三档距离行为：<6 米走+伸手、6–12 米走、>17 米冲刺。计时器：停看(5–8 秒)、随机跑(0.7–5 秒，室内 20%/室外 35% 冲刺)、追丢(10 秒巡逻最后已知)。 |
| **可击杀** | ✅ 4 HP。每铲击眩晕约 0.5 秒。被击时 40% 概率冲刺（1 HP 时 100%）。 |
| **放弃机制** | 失去目标 10 秒后回漫游。最多 10 只。 |
| **刷新** | 室内（可到室外）。偏好：Artifice（7%）。也可由玩家持戏剧面具过久生成。无图鉴条目。 |
| **独特** | 雷达上显示蓝点（像玩家）。模仿玩家行为（转身、偷看、旋转）。被转化玩家保留衣服。每转化一人 20% 死亡罚金。转化时物品删除。 |

### 15. Barber / Clay Surgeon（理发师 / 黏土外科医）

| 维度 | 拆解 |
|------|------|
| **机动性** | 按固定间隔向前跳（8am 时 2.75 秒，到 11pm 加速到 1.25 秒）。跟着节拍移动。 |
